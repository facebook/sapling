This directory contains some locale files that can be installed to tweak some
common system error messages.

In particular this replaces the error message for `ENOTCONN` with advice for
the two common filesystem cases.  In an Eden checkout, it suggests running
`eden doctor`: the error normally means that the checkout has been unmounted,
which can happen if the `edenfs` daemon has died or been restarted.  Compilers
invoked by Buck builds also commonly use `/mnt/gvfs`; an `ENOTCONN` error there
can indicate that prod or VPN network connectivity is unavailable.

Not all `ENOTCONN` errors are related to Eden.  Since this file just globally
replaces the translation it can end up showing this advice in some cases that
aren't relevant.  It can also be generated by socket APIs, normally as a result
of attempting to read from or get the peer name on a network socket that was
never connected, or that was already explicitly shutdown.

If you edit `glibc_en.po` you can regenerate `glibc_en.mo` by running
`msgfmt -o glibc_en.mo glibc_en.po`
(msgfmt is part of GNU gettext)
